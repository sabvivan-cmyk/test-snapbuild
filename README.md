# Snapbuild Landing Page
Продолжение существующего лендинга Snapbuild

## Краткое описание выполненной работы
Основной задачей было воспроизвести существующие блоки сайта и добавить пять новых секций так, чтобы они сохраняли визуальный язык исходной страницы и воспринимались как ее естественное продолжение.

- воспроизведены основные секции существующего лендинга Snapbuild
- добавлены пять новых содержательных секций
- сохранена стилистика исходного сайта
- реализованы интерактивные элементы
- добавлена адаптация под desktop, tablet и mobile
- проведена ручная проверка страницы и визуальная полировка
- настроена production-сборка для публикации на GitHub Pages

## Инструкция по локальному запуску

Требуется Node.js и npm

Установка зависимостей:

```bash
npm install
```

Запуск проекта:

```bash
npm run dev
```

После запуска Vite выведет адрес локального сервера в терминале

Production-сборка:

```bash
npm run build
```

Локальная проверка production-сборки:

```bash
npm run preview
```

## Перечень пяти добавленных секций

### 1. От дизайн-системы до готового материала
Показывает общий процесс работы с платформой: от использования дизайн-системы и постановки задачи до генерации, редактирования и готового результата.

### 2. AI предлагает — вы управляете
Показывает взаимодействие пользователя с AI и возможность контролировать полученный результат.

### 3. Одна платформа — разные задачи
Раскрывает использование Snapbuild для разных рабочих сценариев и задач команды.

### 4. Один материал — разные аудитории
Показывает, как исходный материал может адаптироваться под разные целевые аудитории.

### 5. Одна команда — единый бренд
Показывает работу разных ролей с общей дизайн-системой и сохранение единого визуального языка бренда.

Секции специально отличаются друг от друга по структуре и назначению: используются workflow, переключаемые сценарии, интерактивные состояния и разные варианты композиции.

## Как анализировалась стилистика исходного сайта

Перед разработкой проанализировал следующие моменты:
- типографика и визуальная иерархия
- цветовая палитра
- ширина контейнеров
- вертикальные и горизонтальные отступы
- сетки
- карточки и их радиусы
- кнопки и интерактивные состояния
- использование изображений и продуктовых preview
- расположение и последовательность секций
- вид страницы на разных разрешениях

Для более точного сравнения использовал сохраненную версию исходной страницы, ее ресурсы и скриншоты.

При разработке новых секций старался не создавать отдельный визуальный стиль, а переиспользовать уже существующие паттерны Snapbuild, о чем оповещал Ai агента.

Отдельное внимание уделял расположению новых блоков: они встроены между существующими секциями в соответствии с логикой знакомства пользователя с продуктом, а не просто добавлены в конец страницы.

## Что не удалось реализовать и почему

Не удалось реализовать полного копирования лендинга и исходного кода Snapbuild.

Страница воспроизводилась на основе доступной публичной версии сайта, сохраненных ресурсов и визуального сравнения, поэтому есть отдельные небольшие отличия от оригинала.
